## 💻 Sobre o Projeto

O **Bem Sorrir** é um projeto de site institucional desenvolvido para uma clínica odontológica moderna. O principal diferencial da interface é a sua **experiência de usuário (UX) sincronizada e imersiva**, permitindo que o paciente navegue por meio de flashcards 3D interativos, menu superior ou controladora numérica inferior.

---

## ✨ Funcionalidades Principales

- **🔄 Flashcards com Efeito Flip 3D:** Os cards giram suavemente ao serem clicados, revelando conteúdos detalhados no verso.
- **🔗 Navegação Sincronizada:** Total integração entre o menu superior, os botões numéricos da controladora e os flashcards principais.
- **📍 Localização Integrada:** Card dedicado com mapa interativo do Google Maps incorporado.
- **📞 Canal de Contatabilidade Humanizado:** Informações rápidas de agendamento e canais de atendimento direto.
- **🎨 Design Clean & Moderno:** Interface visualmente atraente, pensada para transmitir confiança e conforto aos pacientes.
